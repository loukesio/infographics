# Τοπική έκδοση με αεροφωτογραφίες Κτηματολογίου

1. Χρειάζεται Python 3 και σύνδεση στο ίντερνετ.
2. Μέσα σε αυτόν τον φάκελο: `python3 serve_local.py` (Windows: `python serve_local.py`).
3. Άνοιξε `http://localhost:8765` και κάνε ζουμ σε Λάρισα, Βόλο, Τρίκαλα ή Καρδίτσα.

Οι αεροφωτογραφίες έρχονται ζωντανά από την υπηρεσία θέασης του Ελληνικού Κτηματολογίου (gis.ktimanet.gr),
μόνο για προβολή σε αυτόν τον υπολογιστή· δεν αποθηκεύονται στον δίσκο. © Ελληνικό Κτηματολόγιο.
Μην ανεβάζεις αντίγραφά τους σε δημόσια σελίδα χωρίς άδεια του Κτηματολογίου.
