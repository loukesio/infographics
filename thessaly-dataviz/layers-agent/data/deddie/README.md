# ΔΕΔΔΗΕ RES hosting margins, Thessaly (read 2026-11-10)
Source: ΔΕΔΔΗΕ «Περιθώρια ΑΠΕ», https://apps.deddie.gr/WebAPE/main.html — Περιφέρεια Θεσσαλίας, όλες οι ΠΕ, κριτήριο
«Σε λειτουργία, με σύμβαση και με οριστική προσφορά». Read in the public web app (table + coordinates the page loads).
- `deddie_margins_thessaly_2026-11-10.csv`: 51 HV/MV transformers; thermal and short-circuit margin (MVA) as published.
  `margin_mva` = min(thermal, short-circuit) — our derivation, consistent with the app's colour (0 = red, <2 = orange, ≥2 = green).
- `deddie_substations_thessaly_2026-11-10.csv`: 29 substations (incl. some just outside the Region serving Thessaly municipalities:
  Δομοκός, Λεοντάρι, Στυλίδα, Πλαταμώνας), summed margins, coordinates from the app.
Margins change as applications are filed; re-read before any decision.
